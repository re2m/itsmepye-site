웹디자인 요구사항 체크리스트

1. 사이트 목적
- 개인 브랜드 소개
- 직접 만든 서비스 홍보
- 정보·가이드북 공유
- 프리랜서 포트폴리오

2. 주요 방문자
- 팔로워
- 서비스 이용자
- 프리랜서 작업을 의뢰할 클라이언트
- 일반 정보 검색 사용자

3. 브랜드 분위기
- 원하는 분위기 키워드 3~5개
- 예: 따뜻한, 실험적인, 귀여운, 미니멀한, 전문적인, 세련된

4. 색상
- 좋아하는 색상
- 피하고 싶은 색상
- 밝은 배경 또는 어두운 배경
- 원하는 색상 코드

5. 폰트 분위기
- 깔끔한 고딕체
- 잡지 느낌
- 손글씨 느낌
- 둥근 글씨
- 개발자·고정폭 느낌

6. 홈 화면 문구
- 메인 제목
- 소개 문구
- 버튼 문구
- 자기소개

7. 페이지별 콘텐츠
- /things: 서비스 이름, 설명, 링크, 이미지
- /info: 가이드북 제목, 설명, 썸네일
- /work: 작업명, 역할, 결과물, 이미지

8. 레퍼런스
- 참고 웹사이트 URL
- Figma 링크
- 스크린샷
- Pinterest·Behance·Dribbble 링크
- 각 레퍼런스에서 마음에 드는 부분

9. 사용할 자료
- 로고
- 프로필 이미지
- 서비스 화면
- 포트폴리오 이미지
- 아이콘

10. 필요한 기능
- 외부 링크
- 앱 설치 버튼
- 이메일 문의
- SNS 링크
- 검색
- 다크모드
- 애니메이션

11. 화면 기준
- 데스크톱
- 모바일
- 태블릿 필요 여부

12. 피하고 싶은 디자인
- 너무 화려한 색상
- 복잡한 메뉴
- 기업 홈페이지 같은 분위기
- 과한 애니메이션
