1️⃣ 아이디어 기획

난이도 ⭐️⭐️⭐️

앱 자체를 만드는건 이제 AI의 역할입니다. 그렇다면 미니앱 수익화를 만들어낼 수 있는 경쟁력은 ‘아이디어 기획’에 있습니다!

사람들이 찾는 서비스가 되기 위해서는 기능이 정말 뛰어나거나, 혹은 재미의 요소를 갖고 있거나를 따져봐야 합니다. 결국 서비스도 릴스 콘텐츠와 동일하게 Hook이 중요하죠🔥

내 머리 속에 있는 아이디어를 어떻게 구체화 할지, 완전히 새로운 아이디어를 어떻게 끄집어낼지 아래 항목들을 직접 채우면서 상세하게 기획해보세요.

💡 10분 안에 기획안 만들기
▶️

1단계: 아이디어 발굴

  1. 내가 최근에 발견한 문제는?

    👉 형식은 없어요. 자유롭게 적어보세요.

  2. 내가 최근에 흥미롭게/재밌게 본 것은?

    👉 형식은 없어요. 자유롭게 적어보세요.

  3. 문제를 해결하기 위한 방법은?

    👉 형식은 없어요. 자유롭게 적어보세요.

  4. 그 해결 방법에 흥미 요소를 녹인다면?

    👉 형식은 없어요. 자유롭게 적어보세요.

▶️

2단계: 아이디어 상세 기획

  1. 서비스 개요
    • 앱 이름: 고해성사, 소라고동
    • 컨셉: 주변에 말 못할 고민이 있을때 소라고동을 당겨보세요. 당신을 웃게할 해결 방안을 제시해줄거에요!
    • 타겟: 스폰지밥 마법의 소라고동을 아는 2030 대학생, 직장인 / 평소 재미있는 짤, 밈을 잘 찾아보는 사람들
    • 유저 플로우: 미니앱 설치 → 메인 화면 랜딩 → 마법의 소라고동 줄 당김 → 고민 육성으로 말하기 → 해결 방안 음성 듣기 → 해결 방안 메시지 이미지 저장 → 공유
  2. 기능 정의
    • 생각나는 기능을 쭉 적어보세요
AI에 요청할 때는 2단계 ‘상세 기획’ 내용만 입력해도 됩니다!

2️⃣ 디자인

난이도 ⭐️⭐️

☝️디자인은 선택 사항입니다. AI에게 아이디어 기획만 입력하면 알아서 기본적인 디자인은 구성해주더라고요.(*AI 마다 디자인 퀄은 다름 주의)

디자인 경험이 없다구요? 괜찮습니다☺️ 우리는 원하는 디자인을 AI에게 학습시켜주면 돼요! 이외로 필요한 부분은 해당되는 도구를 사용해서 제작할 수 있어요.

아래 방법을 따라 원하는 디자인을 AI에게 학습시켜보세요.

💡 AI에게 디자인 학습시키기

2단계: 디자인 레퍼런스 수집

핀터레스트에서 찾은 이미지를 직접 저장하거나, 핀터레스트에 내 보드(UI Design Insight)를 만들어서 그 링크를 AI에게 전달해도 됩니다!

🔎 추천 검색어: UI design / UI Graphic / Product design

*보드 생성 시, 비공개 설정을 ‘해제’ 해야 링크로 공유했을 때 AI가 접근해서 학습할 수 있습니다.

3️⃣ AI 플러그인 연결

난이도 ⭐️

토스 가이드북에서 안내하는 것처럼 ‘클로드 코드’와 ‘코덱스’ 중에 본인이 사용하고 있는 곳에 apps-in-toss 플러그인을 설치해줍니다.

이 작업이 끝나면, 이전에 정리한 아이디어와 디자인을 전달했을 때 AI가 토스 정책에 맞게 알아서 개발을 진행합니다. 앱인토스와 연결이 되어 있어서 중간중간 테스트부터 앱 출시까지 모두 AI와의 대화로 가능해요!

▶️

1단계: Git 설치하기

Git은 비개발자에게 정말 생소한 영역일텐데요! 쉽게 설명하면 코드를 위한 클라우드 서비스 입니다. 각자 운영체제에 맞게 설치해 주세요.

  • Mac 전용 설치 (git-scm.com)
  • Window 전용 설치 (git-scm.com)
▶️

2단계: 플러그인 설치

이제 AI 도구에 토스 플러그인을 설치해야 합니다.

클로드 코드는 우리가 흔히 아는 스페이스에서 설치가 불가능합니다. Mac은 terminal / Window는 PowerShell 을 열고, 아래 순서대로 진행해주세요!

  • 코덱스 Codex
  • 클로드 코드

4️⃣ 본격 개발 적용 및 출시

난이도 ⭐️

이제 플러그인이 설치되었다면 앞에서 정리한 아이디어와 디자인 내용을 전달합니다.

이때 모든 요청을 수행할 때마다 적용된 화면 캡처 이미지를 보여달라고 하면 복잡하게 테스트 빌드할 필요없이 잘 적용되었는지를 확인할 수 있어요.

계속해서 AI가 설정해야 할 부분을 질문으로 던질거에요. 그에 맞게 답변을 해주면 문제 없이 앱 출시가 가능합니다.

▶️

1단계: 기획 내용 설명

어떠한 앱을 만들고 싶은지 기획 내용을 전달해 주세요. 그러면 AI가 그에 맞게 서비스의 뼈대를 만들거에요.

2단계: 디자인 요청사항 전달

1단계에서 AI가 임의로 화면을 구성해서 보여줄거에요. 그러면 수정할 부분을 정확하게 짚어서 수정을 요청해요.

이때 우리가 미리 모아둔 '2️⃣ 디자인'에서 수집한 디자인 레퍼런스 👈 이 레퍼런스를 함께 전달해야 내가 원하는 디자인에 가깝게 결과물을 만들어낼 수 있습니다.

▶️

3단계: 세부 수정

이제 기능적인 부분 / UI 배치 / 텍스트 등 사소하게 수정할 부분을 하나씩 짚어가며 점차 완성물에 가깝게 진행해 주세요.

핸드폰에 ‘토스 앱’이 설치되어 있다면 실제로 작동 테스트까지 해볼 수 있어요!

미니앱 등록에 필요한 정보들이 있으면 AI가 알아서 필요한 부분에 대해 질문을 해줄거에요! 그러면 그에 맞게 답변해주시면 됩니다.
