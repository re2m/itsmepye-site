PlayMCP 카카오 연결 (자동 실행)

카카오톡 나에게 보내기

클로드가 직접 카카오톡 API를 호출하는 방식이 아니라, PlayMCP라는 중간 연결 도구를 통해 카카오톡으로 메시지를 보내는 구조입니다!

💼 준비물

  • 클로드 계정
  • 카카오 계정
  • PlayMCP 연결 (설정 방법은 아래에서)

Step 1. 클로드에서 PlayMCP 연결하기

1️⃣ 클로드에서 연결 설정 열기
채팅창 왼쪽 하단 → 설정 또는 대화창 상단의 도구(Tools) 아이콘 클릭

2️⃣ MCP Apps 탭 선택
도구 메뉴에서 MCP Apps 또는 Connectors 탭을 선택합니다.

3️⃣ PlayMCP 검색 및 연결
검색창에 PlayMCP 또는 KakaoTalk 를 입력하고 Connect 버튼 클릭

4️⃣ 카카오 계정 인증
카카오 로그인 팝업이 뜨면, 카카오 계정으로 로그인하고 권한 허용을 클릭합니다.

⚠️ 카카오 계정 연동 시 '나에게 보내기' 권한이 필요합니다. 다른 사람에게는 보낼 수 없어요!!

Step 2. 카카오톡 자동 발송 테스트

PlayMCP 연결 후, 클로드 채팅창에서 아래처럼 입력해보세요:)

👉 기본 테스트

카카오톡 나에게 "연결 테스트: 클로드와 카카오톡 연결 성공!" 메시지 보내줘

카카오톡에 메시지가 도착하면 연결 완료입니다 ✅

Step 3. 실전 활용 예시

📊 주식/자산 현황 발송

오늘 코스피, 코스닥 현황 조회하고
내 보유 종목 [삼성전자, TIGER미국S&P500] 수익률 계산해서
카카오톡으로 요약 보내줘

✅ 오늘 할 일 발송

오늘 날짜 기준으로 내 노션에서 오늘 할 일 가져와서
카카오톡으로 체크리스트 형태로 보내줘

💡 서비스 아이디어 메모

방금 생각한 아이디어: [아이디어 내용]
이걸 카카오톡으로 나에게 보내줘. 나중에 검토할 수 있게

📰 뉴스/정보 요약 발송

오늘 AI 관련 주요 뉴스 3개 요약해서 카카오톡으로 보내줘

🔥 자동화를 더 강력하게 만들려면

다른 도구와 조합하기

PlayMCP(카카오톡)은 단독으로도 쓸 수 있지만, 다른 MCP 연결과 조합할 때 훨씬 강력해집니다.

  • Google Drive + 카카오톡: 드라이브에서 파일 내용 읽어서 카카오톡으로 요약 발송
  • Gmail + 카카오톡: 중요 이메일 내용을 카카오톡으로 알림
  • Notion + 카카오톡: 노션 데이터 조회 후 카카오톡으로 보고서 발송
  • 웹검색 + 카카오톡: 최신 정보 검색 후 카카오톡으로 정리 발송

활용 아이디어

📌 서비스 만드는 사람을 위한 활용법
  • 베타 고객 모집 현황 → 매일 아침 카카오톡으로 요약 수신
  • 경쟁 서비스 관련 뉴스 모니터링 → 카카오톡 알림
  • 오늘 처리할 고객 피드백 → 출근 전 카카오톡으로 미리 파악
  • 수익/지출 현황 → 주간 리포트 카카오톡 발송
📌 노마드 라이프를 준비하는 사람을 위한 활용법
  • 해외 이동 시 환율 현황 → 출발 전 카카오톡으로 수신
  • 거주 도시 날씨/생활비 정보 → 정기 발송
  • 원격 업무 일정 → 매일 아침 카카오톡 요약

⚠️ 문제 해결

  • 카카오톡 메시지가 도착하지 않을 때
    1. Claude.ai에서 PlayMCP 연결 상태 확인 (Connectors 탭)
    2. 카카오 계정 권한이 올바르게 허용되어 있는지 확인
    3. 연결 해제 후 재연결 시도
  • "도구를 찾을 수 없다"는 메시지가 뜰 때

    → 채팅창 상단의 도구 설정에서 PlayMCP가 활성화되어 있는지 확인해보세요!

  • 연결 후에도 메시지 발송이 안 될 때

    → 클로드에게 "PlayMCP 카카오톡 도구가 연결되어 있어?" 라고 물어보면 현재 상태를 알려줍니다.
